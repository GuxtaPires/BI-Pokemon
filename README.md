## 📌 Sobre o projeto

O **Pokédex Analytics** é um projeto de Business Intelligence desenvolvido no Power BI, com o objetivo de explorar, analisar e visualizar informações do universo Pokémon por meio de uma experiência interativa inspirada na Pokédex.

O projeto contempla os Pokémon da Pokédex Nacional, abrangendo as nove gerações, transformando dados disponibilizados pela PokéAPI em informações visuais e indicadores analíticos.

Além da experiência visual, o desenvolvimento busca aplicar conceitos de engenharia e análise de dados, desde a extração e transformação até a modelagem e visualização.

## 🎯 Objetivos

- Construir uma base de dados integrada a partir de uma API REST.
- Aplicar processos de ETL utilizando Power Query.
- Desenvolver um modelo de dados estruturado.
- Criar indicadores e métricas utilizando DAX.
- Explorar características, atributos e distribuição dos Pokémon.
- Desenvolver dashboards interativos com foco em experiência do usuário e storytelling.

## 📊 Estrutura do dashboard

O projeto está planejado para contemplar quatro áreas principais:

### 1. Pokédex Nacional
- Catálogo interativo de Pokémon.
- Identificação por número e nome.
- Imagens e classificação por tipo.
- Filtros por geração e características.

### 2. Análise de atributos
- HP, Attack, Defense, Special Attack, Special Defense e Speed.
- Comparação de atributos entre Pokémon.
- Rankings e indicadores de desempenho.

### 3. Análise de tipos
- Distribuição de Pokémon por tipo.
- Comparação entre categorias.
- Análise de efetividade e fraquezas.

### 4. Evoluções
- Cadeias evolutivas.
- Estágios de evolução.
- Comparação de atributos entre formas evolutivas.

## 🔄 Processo de desenvolvimento

O projeto será desenvolvido em etapas:

1. **Extração:** integração com a PokéAPI.
2. **Transformação:** tratamento e organização dos dados no Power Query.
3. **Modelagem:** construção de tabelas, dimensões e relacionamentos.
4. **Análise:** desenvolvimento de medidas e indicadores em DAX.
5. **Visualização:** criação de dashboards e recursos interativos.
6. **Documentação:** organização e publicação do projeto no GitHub.

## 🌐 Fonte de dados

Os dados são obtidos por meio da [PokéAPI](https://pokeapi.co/), uma API pública que disponibiliza informações estruturadas sobre o universo Pokémon.

Documentação: https://pokeapi.co/docs/v2
